# Hangman Game

A simple Hangman game made with Python and Pygame. A secret name from CS B1 is picked at random, and you guess it by clicking letters on the screen. Six wrong guesses and our friend sadly hangs himself!

# How to Use

1. Install Python3 and run on some IDE.

2. Install Pygame by running this in a terminal:
   
   pip install pygame
   
3. Make sure hangman.py, png files and audio files are in same folder.

4. Run the game:

   python3 hangman.py

5. Click a letter to guess. Guess the whole name before the drawing is finished to win.
